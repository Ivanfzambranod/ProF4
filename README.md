# SOFTWARE FJ
## Fase 4 - Componente práctico - Prácticas simuladas
### Descripción del proyecto
Software FJ es un sistema desarrollado en Python que permite gestionar clientes, servicios y reservas mediante programación orientada a objetos.
El sistema simula las operaciones de una empresa que ofrece servicios de reserva de salas, alquiler de equipos y asesorías especializadas.
### Objetivo general
Desarrollar un sistema básico de gestión que permita administrar clientes, servicios y reservas, aplicando conceptos de programación orientada a objetos y manejo de excepciones.
### Funcionalidades
- Registro de clientes.
- Validación de información de clientes.
- Registro de servicios.
- Reserva de salas.
- Alquiler de equipos.
- Registro de asesorías especializadas.
- Consulta y cancelación de reservas.
- Validación de disponibilidad.
- Manejo de excepciones.
- Registro de eventos y errores mediante archivos de log.
### Tecnologías utilizadas
- Python.
- Git.
- GitHub.
- Visual Studio Code.
### Estructura del proyecto
- `ProF4.py`: código principal del sistema.
- `registro_eventos.log`: archivo generado durante la ejecución para registrar eventos y errores.
### Ejecución del programa
Para ejecutar el sistema, utiliza el siguiente comando desde la terminal:
```bash
python ProF4.py
```
