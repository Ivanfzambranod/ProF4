# Sistema Integral de Gestión de Clientes, Servicios y Reservas – Software FJ

## Descripción del proyecto

Este proyecto desarrolla un sistema de gestión que permite administrar clientes, servicios y reservas mediante programación orientada a objetos en Python.

## Objetivo

Implementar una aplicación que permita gestionar clientes, registrar servicios, realizar reservas y controlar las operaciones mediante validaciones y manejo de excepciones.

## Funcionalidades principales

- Registro y gestión de clientes.
- Administración de diferentes tipos de servicios.
- Registro y cancelación de reservas.
- Validación de datos ingresados.
- Cálculo de costos de los servicios.
- Manejo de excepciones personalizadas.
- Pruebas para verificar el funcionamiento del sistema.

## Tecnologías utilizadas

- Python.
- Programación orientada a objetos.
- Visual Studio Code.
- Git y GitHub.

## Estructura del proyecto

- `ProF4_Final.py`: archivo principal con el código integrado del sistema.
- `prof4_integrado.py`: archivo correspondiente al aporte de integración de una integrante del grupo.
- `README.md`: documentación del proyecto.
